# 小机房 · 条款与隐私

小机房（`com.weiguang.tinyrack`）的公开法律页面，供应用市场审核与用户查阅。

- 隐私政策：<https://shu4i.github.io/tiny-rack-legal/privacy-policy.html>
- 用户协议：<https://shu4i.github.io/tiny-rack-legal/user-agreement.html>

## 内容来源

本仓库的 HTML 由应用源码仓库的 `docs/store/legal/*.md` 生成，**请勿直接编辑这里的 HTML**。
需要修改条款时，在源码仓库改 Markdown 后重新生成再推送。

生成脚本：`scripts/build-legal-site.py`（应用源码仓库内）。

## 约定

- 页面为纯静态文本，不加载任何外部资源、字体、统计或广告代码。
- **不要**在本仓库放入应用源码、签名材料、数据库或任何个人信息。
- 应用内保留同一份条款的本地全文（应用无网络权限，不依赖本页面）。
